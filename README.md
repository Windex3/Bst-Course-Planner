# Bst-Course-Planner

### Overview
The BST Course Planner is a C++ application that reads course data from a CSV file and organizes it using a Binary Search Tree (BST). The program allows users to view a sorted list of courses or search for a specific course to see its details and prerequisites.

This project demonstrates the use of data structures and algorithms, specifically Binary Search Trees, to efficiently manage and retrieve structured data.

### Features
- Load course data from a CSV file 
- Store courses in a Binary Search Tree
- Display a sorted list of courses using in-order traversal
- Search for a specific course by course number
- Display course title and prerequisites

### Technologies Used
- C++
- Standard Template Library
- File Input/Output
- Binary Search Trees
- Object-Oriented Programming
